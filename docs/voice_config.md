# Configuring the Voice Assistant

Studio P4 includes a built-in Voice Assistant that announces track names, BPM changes, metronome state, and other important events as you work. The voice can be fully configured without leaving the application.

## 1. Opening the Voice Settings

Press the **`V`** key at any time from the main window to open the Voice Settings dialogue box.

*Note: There is currently no MIDI keyboard mapping for the voice settings. The `V` key on your computer keyboard is the only way to access this menu.*

## 2. Navigating the Settings

Once the dialogue is open, use the following keys to navigate and modify the settings:

| Key | Action |
|---|---|
| Up arrow key / down arrow key | Move between settings |
| left arrow key / right arrow key | Decrease / Increase the value of the selected setting |
| `Enter` / `Return` | **Save** changes and close the dialogue |
| `Esc` | **Discard** changes and close the dialogue |

> **Important:** Modifications are only applied once you press `Enter` / `Return` to save. If you close the dialogue with `Esc`, all changes made during that session are discarded and the previous settings are kept.

## 3. Available Settings

There are three configurable settings, navigated in the following order:

### 1. Enable / Disable Voice
Toggles the Voice Assistant on or off entirely. Use the arrow keys to switch between *Activée* and *Désactivée*.

### 2. Speech Rate
Controls how fast the Voice Assistant speaks. Use the arrow keys to adjust the value.

* From **0.5 to 1.0**: adjusts in steps of **0.1**
* From **1.0 to 3.0**: adjusts in steps of **0.25**

A lower value means slower speech; a higher value means faster speech.

### 3. Speech Volume
Controls the volume of the Voice Assistant independently of your system volume. Use the arrow keys to adjust the value from **0.0** (silent) to **1.0** (full volume) in steps of **0.01**.

## 4. A Note on Voice During Configuration

The Voice Assistant remains **fully active inside the settings dialogue**, even if it is currently disabled. This ensures you can always hear spoken feedback while navigating and adjusting the settings, so you are never left without audio guidance during configuration.
